# Design System

## Visual principles
1. Editorial rather than template-like.
2. Large typography and generous negative space.
3. Neutral monochrome foundation with restrained accent colors.
4. Product media gets priority over decorative UI.
5. Glass effects only when they improve hierarchy.
6. Micro-interactions should communicate state, not distract.

## Core surfaces
Obsidian canvas, soft ivory text, muted graphite text, hairline borders, frosted control panels, high-contrast primary actions.

## Components
Navigation, command/search, product cards, preview frames, category rail, filters, wishlist button, cart drawer, pricing panel, customization controls, project timeline, blueprint summary, recommendation rail, request form, quote panel, checkout, account navigation and admin tables.
