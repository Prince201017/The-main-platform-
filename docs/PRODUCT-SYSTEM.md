# Product System

## Product types
Asset/component, section, page, website template, web application, SaaS concept, application, service, custom project, subscription/maintenance.

## Customer flow
Discover → Preview → Save → Customize → Request/Quote → Cart → Checkout → Production → Review → Deployment → Maintenance.

## Customer blueprint
The blueprint is a first-party preference model built from explicit account activity and consented product interactions. Store facts such as viewed products, wishlist items, saved components, customization choices, business category supplied by the customer, and stated budget/requirements. Do not infer sensitive traits.

## Recommendation engine
Use the blueprint to recommend relevant products and services. Recommendations should be explainable, frequency-controlled and opt-out capable.

## Custom request
Customer can submit a written brief, business field, required pages/features, budget, timeline, references and uploads. The system converts this into a structured project brief for quotation.
