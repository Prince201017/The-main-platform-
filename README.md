# The Main Platform

A premium design-commerce and digital services platform.

## Vision
Discover premium websites, web apps, SaaS concepts, applications, digital assets and online services; personalize a concept; save it to a customer blueprint; request custom work; purchase a license or service; and receive a privately built/deployed product without exposing proprietary source code.

## Pillars
- Premium showcase and discovery
- Website / web-app / SaaS / application marketplace
- Live product previews
- Customer accounts, wishlist, cart and projects
- Customer preference blueprints based on consented interactions
- Reference/design request workflow
- Custom quotes and checkout
- Asset licensing and protected delivery
- Admin workspace
- Recommendation and lifecycle automation architecture
- Privacy, terms, licensing and consent controls

See docs/ for architecture, product system, data model, security, design system and roadmap.

## Planned stack
Next.js + TypeScript, Tailwind CSS, shadcn/ui, Framer Motion, Supabase, a payment provider, and a private build/deployment environment.

## Source protection
This repository is the platform shell and design system. Proprietary asset implementation, private build tooling, secrets and production-only credentials must remain outside any public repository. Browser-delivered code can always be inspected; the goal is to protect the private source/build system and reusable proprietary library.
